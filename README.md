# Live Text — учитель видит ответы и код учеников в реальном времени

## Режимы комнаты (выбирает учитель в панели)
- **Текст** — обычное поле ввода.
- **Python** — у ученика два окна: «Код» (редактор с подсветкой) и «Вывод и ввод» (терминал).
  Кнопки: Запустить (Ctrl+Enter), Стоп, Очистить вывод. `input()` работает как в терминале.
  Python запускается прямо в браузере ученика (Pyodide), сервер код не выполняет.
  Учитель видит у каждого ученика код, вывод и статус («выполняется», «ждёт ввода»).
  Клик по имени ученика открывает его работу крупно.

- **HTML / CSS / JS** — слева вкладки HTML, CSS, JS, справа готовая страница (обновляется сама через 0,6 с).
  Можно писать только содержимое страницы (без `<html>` и `<body>`) или полный документ. Ссылки на `style.css` и `script.js`
  подставляются автоматически. Ошибки JS и `console.log` показываются в консоли под страницей.
  На телефоне окна идут друг под другом, на компьютере рядом. Защита от бесконечных циклов (прерываются через ~1,5 с).
  У учителя в этом режиме не плитки, а список учеников слева: по клику открывается его работа. В центре код во вкладках
  HTML / CSS / JS (обновляется, пока ученик печатает, изменения подсвечиваются; галочка «следить за вводом» сама переключает
  вкладку на ту, где идёт набор), справа страница ученика с консолью. Галочка «выполнять JS» отключает скрипты ученика.

## Правка кода ученика учителем (во всех режимах)
- **Текст и Python:** кликните прямо по тексту в плитке ученика и правьте на месте; клик в любое другое место закрывает правку.
  Клик по имени ученика по-прежнему открывает крупное окно (там правка тоже включена).
- **HTML / CSS / JS:** выберите ученика в списке и правьте код в центре. Кнопка «Правка включена» нужна только чтобы
  временно запретить правки (защита от случайных нажатий).
Ваши изменения сразу появляются у ученика и выделяются жёлтым, вверху у него баннер «Учитель внёс правки» с кнопкой
«Понятно». Если правка во вкладке CSS или JS, на этой вкладке у ученика мигает точка. Ученик может продолжать печатать,
его набор не теряется. Правка работает и при заблокированном вводе.

## Панель учителя
- **Шапка:** код комнаты и адрес (клик копирует), переключатель режима (Текст / Python / HTML), счётчик учеников,
  кнопка блокировки ввода, меню «Вид» (размер текста и плиток), меню «⋯» (скачать ответы, очистить ответы, новая комната),
  кнопка «📊 Панель».
- **Правая панель** (кнопка «Панель» скрывает и показывает, выбор запоминается): таймер, поднятые руки, таблица «Кто закончил».
- **Таймер:** ▶ Старт / ⏸ Пауза / ↺ Сброс (сбрасывает и таблицу). Поле «мин» — обратный отсчёт; пусто — секундомер.
  Таймер виден и ученикам. Время в таблице — по таймеру на момент нажатия «Я всё!» (если таймер не запускали, только порядок).
- **Руки:** клик по имени открывает ученика, ✕ опускает руку, при новой руке короткий звук.
- **Таблица:** ✕ убирает ученика, «Очистить» очищает таблицу, не трогая таймер.

## Страница ученика
Сверху одна панель: имя, таймер, статус, «✋ Поднять руку», «✅ Я всё!» и «🏆» (таблица лидеров выезжает справа, закрывается ✕).

## Задание, тёмная тема, список, окна, реакции
- **Задание (task)**: учитель вводит текст и время в карточке под лидербордом (скрывается вместе с ним). У учеников — полоса сверху на всю ширину (на телефоне — кнопка «Задание», открывает панель). При «Отправить с таймером» таймер запускается с лимитом, лидерборд очищается.
- **Тёмная тема**: кнопка в шапке, запоминается в браузере (у учителя и ученика отдельно).
- **Список учеников** (текст/Python): переключатель «плитки / список» — слева список, справа выбранный ученик; правка кода прямо в окне.
- **Окна**: в HTML-режиме окна — широкие полосы одна под другой (код → страница; список учеников стоит в боковой панели под заданием, а если панель скрыта или экран узкий — сверху), стрелки ↑↓ меняют порядок; в HTML-режиме и у ученика окна можно переставлять (перетаскиванием или стрелками ◀ ▶) и скрывать; скрытые возвращаются кнопками над рабочей областью. Расположение запоминается.
- **Реакции**: ученик выбирает смайл — у всех внизу слева всплывает пузырь с именем. Защита от спама: можно слать свободно, но больше 3 реакций за 10 секунд — и ученик уходит в паузу на 15 секунд (`REACTION_BURST`, `REACTION_WINDOW_MS`, `REACTION_COOLDOWN_MS` в server.js). Учитель может выключить показ реакций в меню «Вид».
- **Таймер** (состояния: не запущен → идёт ⇄ пауза → время вышло): длительность вводится как `5` (минуты) или `2:30`, пусто — секундомер. До запуска табло сразу показывает введённое время, поле можно менять, «+/−» тоже. «Сброс» возвращает таймер в «не запущен» с исходной длительностью и не трогает лидерборд. Время вышло → табло 00:00, ввод у учеников закрывается автоматически, кнопка «Заново», у учителя и у учеников звучит сигнал; «+30 с / +1 мин / +5 мин» продолжают отсчёт и открывают ввод. Новый раунд с заданием запускает таймер с нуля и очищает таблицу.
- **Запуск Python у учителя**: в окне ученика (режим Python) кнопка ▶ у «Вывод программы» запускает его код в браузере учителя; ученик этого не видит. Стрелка возврата показывает вывод самого ученика.
- Новые файлы: `public/ui.css`, `public/theme.js`, `public/icons.svg`.

## Состав проекта
- `server.js` — сервер (Node.js + WebSocket), всё хранится в памяти
- `package.json` — зависимости (express, ws, compression)
- `public/index.html` — страница ученика
- `public/teacher.html` — панель учителя (адрес `/teacher`)
- `public/preview.js` — сборка страницы ученика из HTML/CSS/JS (общий модуль)
- `public/py-worker.js` — запуск Python в отдельном потоке (из-за него работают «Стоп» и input())
- `public/vendor/` — редактор кода (CodeMirror) и сам Python (Pyodide), ~14 МБ

## Запуск у себя
1. Node.js 18+ (nodejs.org)
2. В папке проекта (в командной строке `cmd`, не PowerShell): `npm install`, затем `npm start`
3. Учитель: http://localhost:3000/teacher · Ученик: http://localhost:3000

## Обновление на Render
Загрузите изменённые файлы в репозиторий на GitHub (Add file → Upload files, одноимённые файлы заменятся)
и нажмите Commit changes. Render сам пересоберёт сайт за 2-5 минут.
Не обновляйте во время урока: комнаты и ответы при перезапуске пропадают.

## Замечания
- Первая загрузка Python у ученика занимает 5-30 секунд (около 14 МБ), потом браузер её кэширует.
- Доступны только встроенные модули Python (math, random, datetime и т.п.). numpy/pandas пока не подключены.
- Заголовки COOP/COEP на сервере нужны для input(); не удаляйте их из `server.js`.
- Данные хранятся в памяти: перед концом урока нажмите «Скачать ответы».
