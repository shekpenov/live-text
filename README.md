# Live Text — учитель видит ответы и код учеников в реальном времени

## Режимы комнаты (выбирает учитель в панели)
- **Текст** — обычное поле ввода.
- **Python** — у ученика два окна: «Код» (редактор с подсветкой) и «Вывод и ввод» (терминал).
  Кнопки: Запустить (Ctrl+Enter), Стоп, Очистить вывод. `input()` работает как в терминале.
  Python запускается прямо в браузере ученика (Pyodide), сервер код не выполняет.
  Учитель видит у каждого ученика код, вывод и статус («выполняется», «ждёт ввода»).
  Клик по имени ученика открывает его работу крупно.

## Состав проекта
- `server.js` — сервер (Node.js + WebSocket), всё хранится в памяти
- `package.json` — зависимости (express, ws, compression)
- `public/index.html` — страница ученика
- `public/teacher.html` — панель учителя (адрес `/teacher`)
- `public/py-worker.js` — запуск Python в отдельном потоке (из-за него работают «Стоп» и input())
- `public/vendor/` — редактор кода (CodeMirror) и сам Python (Pyodide), ~14 МБ
