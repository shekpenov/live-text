# Live Text — учитель видит ответы учеников в реальном времени

## Что внутри
- `server.js` — сервер (Node.js + WebSocket), хранит всё в памяти
- `public/index.html` — страница ученика (код комнаты + имя + поле ввода)
- `public/teacher.html` — панель учителя (адрес `/teacher`)

## Запуск на своём компьютере (проверка)
1. Установите Node.js 18+ (https://nodejs.org)
2. В папке проекта: `npm install`, затем `npm start`
3. Учитель: http://localhost:3000/teacher
4. Ученик: http://localhost:3000 (откройте в другой вкладке или окне)

## Выкладка в интернет (Render.com, бесплатно)
1. Создайте репозиторий на GitHub и загрузите туда все файлы проекта (без папки node_modules)
2. На render.com: New → Web Service → подключите репозиторий
3. Build Command: `npm install`  ·  Start Command: `npm start`  ·  Plan: Free
4. После деплоя получите адрес вида https://live-text-xxxx.onrender.com
5. Учитель: адрес + `/teacher`. Ученики: просто адрес

Важно: на бесплатном тарифе Render сервер «засыпает» через 15 минут без запросов и просыпается около минуты. Откройте страницу учителя за 5-10 минут до урока.

## Замечания
- Данные хранятся в памяти: при перезапуске сервера комнаты и ответы пропадают. Перед концом урока нажмите «Скачать ответы».
- Ученик не получает ничего, кроме своего текста. Чужие ответы видит только учитель по секретному ключу, который хранится в его браузере.
